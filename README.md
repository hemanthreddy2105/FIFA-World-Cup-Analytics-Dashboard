# ⚽ FIFA World Cup Analytics Dashboard

## 📌 Project Overview

The FIFA World Cup Analytics Dashboard is a six-page interactive Power BI project designed to explore the history of the FIFA World Cup from multiple perspectives, including tournaments, teams, players, rivalries, stadiums, referees, and operational insights.

The dashboard combines advanced data modeling, DAX measures, Power Query transformations, and interactive visualizations to provide meaningful insights into FIFA World Cup history.

---

## 🎯 Objectives

- Analyze FIFA World Cup tournaments from 1930 onwards.
- Compare national team performances.
- Explore legendary player statistics.
- Study historical tournament trends.
- Analyze stadiums, referees, managers, and disciplinary records.
- Build a professional multi-page Power BI dashboard using best practices.
